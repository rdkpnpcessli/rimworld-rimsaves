## Overview

RimSaves replaces RimWorld's minimal save management with a named slot system supporting tags, screenshots, and descriptions per save, configurable autosave compression to reduce save file size and frequency, save file cloud backup integration, and a save browser with searchable metadata and thumbnail previews.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld RimSaves** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Named Save Slots** | Saves with custom names, tags, and notes for organized game management |
| **Save Compression** | Configurable gzip compression reduces save file sizes by up to 70% |
| **Autosave Control** | Flexible autosave intervals with max-save-count rolling management |
| **Save Browser** | Searchable save list with timestamps, colony thumbnails, and metadata |
